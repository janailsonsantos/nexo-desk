# Nexo Desk

Sistema de chamados internos desenvolvido em um treinamento prático
de desenvolvimento full stack.

## Problema

Solicitações de suporte recebidas por mensagens podem se perder e
dificultar o acompanhamento dos atendimentos.

O Nexo Desk pretende centralizar a abertura, a organização e a
resolução desses chamados.

## Funcionalidades planejadas

- Cadastro e autenticação de usuários.
- Abertura de chamados com título, descrição e prioridade.
- Listagem e filtros de chamados.
- Comentários nos atendimentos.
- Atualização do status dos chamados.
- Painel com indicadores básicos.

## Tecnologias planejadas

- Front-end: React e TypeScript.
- Estilos: CSS.
- Back-end: Node.js, Express e TypeScript.
- Banco de dados: PostgreSQL.
- Versionamento: Git e GitHub.
- Testes: unitários, de componentes, de integração e ponta a ponta.

## Status

Projeto em preparação. A aplicação ainda não foi implementada.

## Fluxo de contribuição

1. Criar uma branch para a tarefa.
2. Implementar e verificar as alterações.
3. Registrar commits com mensagens claras.
4. Enviar a branch ao GitHub.
5. Abrir uma pull request.
6. Revisar e ajustar antes do merge.
